An LLM is a type of AI model that excels at understanding and generating human language.
They are trained on vast amounts of text data, allowing them to learn patterns, structure, 
and even nuance in language. These models typically consist of many millions of parameters.  

Transformer architecture—a deep learning architecture based on the “Attention” algorithm.  
There are 3 types of transformers:  
1.Encoders   
 BERT from Google  
 Use Cases: Text classification, semantic search, Named Entity Recognition  
2. Decoders
  Example: Llama from Meta  
  Use Cases: Text generation, chatbots, code generation  
3. Seq2Seq (Encoder–Decoder)   
  Example: T5, BART
  Use Cases: Translation, Summarization, Paraphrasing
